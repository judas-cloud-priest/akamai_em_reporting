# 프로그램의 목적 : Akamai API를 호출하여 billing data 및 traffic reporting data를 추출하고 그 값들을 정해 진 포맷의 excel file에 기록한 다음, 그 엑셀 파일에 있는 데이터를 기반으로 미리 준비된 powerpoint template을 사용하여 트래픽 리포트 pptx 파일을 작성한다.

## High level에서의 프로그램의 구성 요소

1. Akamai EdgeGrid Credential (https://techdocs.akamai.com/developer/docs/edgegrid)을 이용하여 API를 호출하는 wrapper function. 이 함수는, https://techdocs.akamai.com/reporting/reference/rate-limiting 에 정의된 API rate limit을 준수하도록 API 호출의 속도를 조절해야 한다.

2. 응답으로 얻은 API response는, user의 root 디렉토리에 위치한 캐시 파일에 결과값을 저정하며, 동일한 API 호출에 대해서는 캐시에서 있는 값을 우선적으로 사용하도록 한다. (단, 캐시된 데이터의 date가 1주일 보다 짧으면 혹시 imcomplete data일 수 있으므로 API 호출을 수행하도록 한다.)  

3. 읽어온 API response 값을 이용해 엑셀 파일을 업데이트하는 함수. (해당 엑셀 파일이 아직 생성되지 않았으면 새로 생성하고, 이미 존재하면 그 파일을 업데이트함)

4. 업데이트된 엑셀 파일에 있는 데이터를 이용해, 이미 준비된 powerpoint template의 양식에 따라 트래픽 리포트 pptx 파일을 작성하는 함수.

1. 전체 URL 중 offload가 높은 순 또는 낮은 순으로 N개를 추출하여 table에 채워 넣기
2. offload 가 XX% 이하 또는 이상인 URL 상위 또는 하위 N개를 추출하여 table에 채워 넣기
3. regular expression을 활용해 특정 확장자 또는 path에 match 되거나 match 되지 않는 URL 만 추출.
4. 위 모두 조합을 AND 또는 OR 하는 연산을 가능해야 함.
